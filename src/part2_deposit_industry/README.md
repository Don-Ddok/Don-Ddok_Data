# 저축성 예금(거치식·적립식) 업종별 LP 분석

담당: 신다혜 · 결과 문서: [Don-Ddok_Docs `분석결과/파트2_수신채널심화/`](https://github.com/Don-Ddok/Don-Ddok_Docs/tree/main/분석결과/파트2_수신채널심화)

수출 충격이 올 때 외환 거래가 있는 법인(노출)의 거치식·적립식 예금이 외환 거래가 없는 법인(비노출)과 다르게 움직이는지 국소투영(LP) 패널회귀로 봅니다. 결과를 만든 노트북을 올렸고, 법인ID가 찍히는 출력 한 곳만 지웠습니다(아래 참고).

## 실행 환경

- 로컬 Windows, Jupyter. 필요한 라이브러리: `pandas`, `numpy`, `matplotlib`, `openpyxl`, `linearmodels`
- 그래프 글꼴은 `Malgun Gothic`(Windows 기본)
- 노트북 첫 코드 셀의 경로(`file_bank`, `file_customs`)는 분석자 로컬 폴더 기준입니다. 다시 실행하려면 자기 환경에 맞게 바꿉니다.
  - `data.xlsx`: iM뱅크 법인 익명데이터(비공개, 이 저장소에 없음. `/data/raw`에 두고 경로 변경)
  - `export_region.csv`: [`/data/external/export_region.csv`](../../data/external/export_region.csv)와 같은 값(숫자 표기 `-9`/`-9.0` 차이만 있음)

## 노트북

| 순서 | 파일 | 내용 |
|---|---|---|
| 01 | `01_deposit_industry_lp_initial.ipynb` | 초기 분석. 처치군(직전 365일 안에 외환실적이 있는 법인)만으로 패널을 만들어 업종별 거치식·적립식 LP(h=0~12)를 추정 |
| 02 | `02_deposit_industry_lp_revised.ipynb` | 리뷰 반영 수정본(역할분담표 v2 ②). 전체 법인으로 대조군을 넣고 팀 표준 식의 β₃(노출 − 비노출 격차)를 추정. 달력 통제(외환노출 × 월 더미), 법인 군집 SE, 3개 업종(기계·도매·1차 금속). 강건성: 이중 군집 SE, 지역×연월 FE, 잔액 양수 관측만, 2023 기준 처치, 사전 추세, leave-one-out, 보유 여부 LP |

**01은 대조군이 없어 결과를 해석에 쓰지 않습니다. 팀 결과는 02 기준입니다.** 02의 모든 결과는 사후에 업종을 고른 **[탐색적 분석]**입니다.

## 02 주요 결과 (요약)

| 업종 | 거치식 | 적립식 |
|---|---|---|
| 1차 금속 | h=3 −0.021, h=6 −0.048, h=12 −0.094 (모두 p<0.05) | 음(−)이지만 h=6만 p=0.065 |
| 기타 기계 | h=12에서만 −0.082 (p=0.036) | 유의하지 않음 |
| 도매·상품중개 | 0 근처 | 0 근처 |

- 거치식 결과는 잔액 규모가 아니라 **보유 여부(개설·유지)**의 차이입니다. 잔액 양수 관측만 쓰면 0 근처이고, 보유 여부 LP에서는 1차 금속 h=3·6·12가 유의합니다.
- 자세한 해석은 노트북 9절과 Docs의 `거치식적립식_업종반응_수정본.pdf`에 있습니다.
